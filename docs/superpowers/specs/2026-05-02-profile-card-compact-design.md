# 资料卡紧凑版设计

## 目标

资料卡页面去掉“教练档案”大标题区，直接以“八月资料卡”作为页面第一个内容模块。整体沿用首页的暖色背景、白色半透明卡片、深色粗标题、橙色强调色，让页面层级更统一。

## 选定方向

采用 C 方案：极简档案卡。

首模块不再做大面积 hero。模块内部左侧承载用户身份信息，右侧保留小尺寸柴犬教练图作为品牌点缀。页面重点从“教练介绍”转为“用户资料”，减少顶部留白和重复文案。

## 页面结构

1. 顶部导航仍显示页面标题“资料卡”。
2. 第一个模块为个人资料卡：
   - 主标题：`八月`
   - 辅助标题：`资料卡`
   - 简短说明：`霸气按目标盯进度`
   - 信息标签：目标、体重、身高
   - 元信息：性别、年龄
   - 右侧小柴犬教练图，作为视觉标识，不抢主信息。
3. 第二个模块为热量计划卡，保留现有内容层级：
   - 建议摄入为最高优先级
   - 基础代谢、习惯消耗、目标调整为次级指标
   - 三大营养素顺序保持：蛋白质、碳水、脂肪
4. 底部保留“修改资料”主按钮和鼓励文案。

## 视觉规范

- 背景沿用首页的暖米色渐变。
- 卡片统一使用白色半透明底、淡橙描边、柔和阴影。
- 主标题使用深色高字重，大小低于首页品牌标题，高于普通 section 标题。
- 标签使用浅橙底、棕橙文字，避免新的色系。
- 柴犬图尺寸控制在资料卡右上角，不与热量计划卡争抢视觉中心。

## 修改范围

- `miniprogram/pages/profile/index.wxml`
- `miniprogram/pages/profile/index.wxss`

如视觉统一需要，可小幅补充 `miniprogram/app.wxss`，但不再扩大影响面。

## 验证

- 运行 `npm test`，确认计算与数据流不受影响。
- 在微信开发者工具检查资料卡首屏：
  - 顶部不再出现“教练档案”大标题区。
  - “八月资料卡”作为第一个内容模块。
  - 热量计划模块上移，首屏显示更多有效内容。
  - 三大营养素顺序仍为蛋白质、碳水、脂肪。

## 风险

- 如果柴犬图过小，品牌感会变弱；需要在紧凑和角色感之间微调。
- 资料卡首模块信息较多，小屏设备上可能需要压缩标签间距。
